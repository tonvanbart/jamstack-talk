## Slides "van LAMP naar JAM"

Markdown voor het slide deck van de talk "van LAMP naar JAM" op de NLLGG landelijke bijeenkomst van 10 oktober 2026.
De slides zijn geschreven in Markdown en het deck is gegenereerd met [Marp](https://marp.app/), Github zal het 
bestand [jamstack-talk.md](jamstack-talk.md) al leesbaar weergeven. Het tabje "code" geeft de ongeformatteerde Markdown,
dan zijn ook de speaker notes van de slides te zien.
